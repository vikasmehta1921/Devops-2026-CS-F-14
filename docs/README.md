## Quick Start

1. Start Backend:
   cd backend
   npm install
   npm run dev

2. Start Frontend (new terminal):
   cd frontend
   npm install
   npm run dev

3. Seed Admin Account:
   cd backend
   npm run seed:admin
   Admin: admin@example.com / Admin@12345

4. Open: http://localhost:5173
