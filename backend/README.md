# 🏠 Smart Rental & Roommate Finder

A full-stack web application that helps users find rental properties and suitable roommates in one platform.

The project is developed using **Full Stack Development (FSD)** and **DevOps principles**, with separate frontend, backend, and DevOps branches.

---

## 📌 Project Overview

Smart Rental & Roommate Finder provides a simple platform where users can:

- 🔐 Register and login
- 🏠 Search and view rental properties
- 👥 Find suitable roommates
- ❤️ Save favorite properties
- 📅 Make and manage bookings
- 📜 View booking history
- 💬 Communicate through messages
- ⭐ Submit reviews
- 🔔 Receive notifications
- 📋 Send property enquiries
- 👨‍💼 Manage properties as an owner
- 🛠️ Manage the platform as an administrator
