# Smart Rental and Roommate Finder

## 📌 Project Overview

Smart Rental and Roommate Finder is a full-stack web application that helps users find rental properties and suitable roommates.

The project is developed using:

- Frontend: React.js
- Backend: Node.js + Express.js
- Database: MongoDB
- DevOps: Git, GitHub, Docker and Jenkins

---

# 🚀 DevOps

The DevOps part of this project is responsible for containerization, CI/CD automation, and integration of the frontend and backend.

## 🛠️ DevOps Technologies

- Git
- GitHub
- Docker
- Docker Compose
- Jenkins
- GitHub Webhook
